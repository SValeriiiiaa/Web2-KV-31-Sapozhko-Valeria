Мета:

Ознайомитись із засобами мови Javascript та навчитись їх застосовувати побудови Web-інтерфейсу користувача.

Загальне завдання:

Розробити функціональність для статичних сторінок Web-додатку першої лабораторної роботи із використанням шаблону MVC.

Статичний Web-сайт має містити сторінки:

реєстрація користувача (поля: ім’я, email, стать, дата народження) вхід до сайту (поля: email, пароль) профіль користувача (поля у табличному вигляді) - про додаток (емблема додатку, короткий опис додатка) робоча сторінка додатка (розробляється самостійно студентом відповідно до обраної тематики) Всі сторінки мають бути в єдиному стилі, і включають: заголовок, меню, основний вміст, нижній колонтитул (footer). Зауваження: Web-фреймворки (ReactJS, AngularJS, VueJS) не використовувати!

Обрана тематика додатку: Платформа для вивчення іспанської мови «EsPass».

EsPass - це сучасна вебплатформа для вивчення іспанської мови з естетичним дизайном на Bootstrap 5. Проєкт пропонує гейміфіковане навчання через інтерактивні лекції, розумний словник та систему особистих досягнень, що дозволяє користувачам ефективно опановувати мову та відстежувати свій прогрес у реальному часі.

У першій лабораторній роботі було реалізовано статичний інтерфейс платформи з набором сторінок, навігацією, картками прогресу, словником, уроками, досягненнями, налаштуваннями, тарифами, входом і реєстрацією. У другій лабораторній роботі цей інтерфейс було доповнено JavaScript-функціональністю.
